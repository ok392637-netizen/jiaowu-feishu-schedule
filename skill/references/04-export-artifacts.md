# 04 · 交付文件规格（xlsx / csv / ics）

> 用户要“一份有详细信息的表格”时，三件套一起给：Excel 给人看、CSV 给飞书导入、ICS 给手机日历。三份必须**同源同数**。

## 1. Excel（`*_详细课表.xlsx`）

4 个工作表，结构固定：

### 1.1 `课次明细`（N 条上课记录）

| 行 | 内容 |
|---|---|
| 1 | 空行（留白） |
| 2 | `详细课表` ／ `2026–2027 学年第一学期` |
| 3 | `排课记录` ｜ `N` ｜ `课程数` ｜ `M` |
| 4 | 来源说明：教务系统地址 + 抓取日期 + “所有钟点为北京时间，保留原始排课及内容中的差异” |
| 5 | **表头**（23 列） |
| 6–154 | 数据行 |

23 列顺序（不可乱，用户会直接筛选）：

```
日期, 开始, 结束, 课程, 授课内容, 授课教师, 教学场地, 教学周, 星期, 节次,
教学环节, 教学形式, 校区, 教学班, 考核方式, 课序号, 课程编号, 平台课程编号,
排课人数, 上课人数, 数据提示, 源备注, 源记录ID
```

格式要求：
- 冻结窗格 `E6`（前 5 行 + 前 4 列固定）；
- 日期单元格为**原生日期** + `yyyy-mm-dd`；开始/结束为**原生时间** + `hh:mm`；
- 表头深蓝底（FF173B60）白字加粗；隔行浅色底（可选）；
- 列宽参考：`13,9,9,30,55,22,27,9,11,23,13,13,12,45,12,10,14,17,10,10,64,32,15`；
- 空场地写 **未提供**（可读性约定），不要留空也不要编造教室。

### 1.2 `课程总览`

第 5 行表头：`课程, 授课教师, 排课记录数, 理论记录数, 实验记录数, 首次上课, 最后上课, 考核方式, 已提供教学场地`；第 6 行起每门课一行，共 若干门，`排课记录数` 合计必须与 normalized 的上课记录数相等。教师用「、」连接并按首次出现顺序去重。

> 用**静态数值**而不是 `COUNTIFS` 公式：脚本生成的 xlsx 没有缓存值，WPS/飞书预览里公式可能显示空白。若坚持用公式，必须再用 LibreOffice 重算一次（见 `office-recalculate`）。

### 1.3 `考试安排`（3 条）

表头：`考试日期, 开始, 结束, 课程, 考场, 校区, 座位号, 考试人数, 监考教师（接口）, 教学周, 节次, 数据提示, 源记录ID`
说明行要注明：监考教师字段取自接口，教务页面可能显示星号。

### 1.4 `选课时间`（6 条）

表头：`选课阶段, 开始时间, 结束时间, 说明, 源记录ID`；注明 2 条是历史选课，不计入上课日历。

## 2. CSV（`*_飞书导入.csv`）

- **UTF-8 无 BOM** + **CRLF**；用标准 csv 模块（内容里含换行/逗号，必须正确加引号）。
- 27 列，全量行（全部上课 + 全部考试）：

```
日程标题, 类型, 开始时间, 结束时间, 课程, 授课内容, 授课或监考教师, 校区, 教学场地,
教学周, 星期, 节次, 教学环节, 教学形式, 教学班, 考核方式, 课程编号, 平台课程编号, 课序号,
排课人数, 上课人数, 座位号, 源备注, 数据提示, 源记录ID, 学期, 时区
```

- 开始/结束：`YYYY-MM-DD HH:MM:SS`；`类型`：`上课/考试`；空值写空串。
- 无 BOM 对飞书导入友好；如果用户还要用 Excel 双击打开，另存一份带 BOM 的副本（`*_飞书导入_BOM.csv`），不要替换原件。

## 3. ICS（`*_北京时间.ics`）

- CRLF；`BEGIN:VCALENDAR` + `VERSION:2.0` + `PRODID` + `CALSCALE:GREGORIAN` + `METHOD:PUBLISH`
- `X-WR-CALNAME`（含姓名/学期）+ `X-WR-TIMEZONE:Asia/Shanghai`
- 必须内嵌 `VTIMEZONE`：`TZID:Asia/Shanghai`，`STANDARD`，`DTSTART:19700101T000000`，`TZOFFSETFROM:+0800`，`TZOFFSETTO:+0800`
- 事件时间用 **TZID 形式**：`DTSTART;TZID=Asia/Shanghai:20260907T083000`，`DTEND` 同格式。
  **不要转成 UTC 的 `Z`**——转错会整体偏 8 小时，而且用户看到的时间会和课表不一致。
- 每条 VEVENT：`UID`（唯一）、`DTSTAMP`、`SUMMARY`、`DESCRIPTION`、`LOCATION`、`CATEGORIES`（上课/考试）。
- 考试 SUMMARY 用 `[考试] 课程名` 前缀；DESCRIPTION 写考场/座位号/人数/监考教师。
- 物理行 **≤75 字节**（中文按 UTF-8 字节算），超长要折行（续行以空格开头）。

## 4. 自检（脚本内置，失败即退出非 0）

| 项 | 判定 |
|---|---|
| xlsx | 4 表存在；课次明细与 normalized 上课记录数一致；课程总览合计一致；考试/选课表存在；冻结窗格存在 |
| csv | 27 列 × 全量数据行；无 BOM；每行列数一致；中文无替换符 |
| ics | VEVENT 数与 normalized 事件数一致；VTIMEZONE 存在；TZID 形式；最大物理行 ≤75；DTSTAMP/UID 齐全 |
| 三份一致 | 源记录 ID 集合完全相等；课程/时间/教师/场地逐条一致 |

## 5. 独立验收（不要只信生成脚本）

```bash
python scripts/feishu_calendar_verify.py --normalized normalized.json   # 日历侧
# 表格侧：用 openpyxl(data_only=True) 重新打开，逐行比对，别复用生成时的内存对象
```

本次实战的多重核对结果（可作为目标值）：xlsx 行数、CSV 行数、ICS 事件数都与 normalized 一致，三份 ID 集合相等；ICS 时间端点与源北京时间严格一致；xlsx 与 CSV 交叉字段 0 差异。

## 6. 落盘位置

建议 `outputs/<学校>-<学期>/`，文件名带姓名和学期（如 `张三_2026-2027-1_详细课表.xlsx`）。给用户的“最终文件”最好再复制一份到他好找的目录（如 `Downloads\课表导出-<学期>\`），并在同目录放一份 `使用说明.md`。
