# 01 · 教务系统接口与数据口径（示例高校）

> 目标：拿到**带起止钟点和教学内容**的课表。官方“导出”按钮给的是周次网格，缺这两样，只能当校验基准。

## 1. 系统入口

| 用途 | 地址 |
|---|---|
| 门户 | `https://jw.example.edu.cn/new/welcome.page?ui=new` |
| 个人课表页 | `https://jw.example.edu.cn/new/student/xsgrkb/main.page`（iframe 内是 `.../xsgrkb/week.page?xnxqdm=202601`） |
| 首页桌面（含日历组件） | `https://jw.example.edu.cn/new/desktop` |
| 官方导出 | `https://jw.example.edu.cn/new/desktop/printCalendar` → `calendar.xls` |

- `xnxqdm` 是学期代码：`202601` = 2026-2027 学年第一学期（换学期要改）。
- 全部接口都要登录 cookie；未登录会 302 到登录页。**不要尝试用 UI 自动化逐格点课表**，只取一次接口响应。

## 2. 核心接口（一次拿全学期）

```
POST /new/desktop/getCalendar
Content-Type: application/x-www-form-urlencoded; charset=UTF-8
Cookie: <已登录会话>

d1=2026-08-01 00:00:00
d2=2027-03-01 00:00:00
```

- 返回 **JSON 数组**（不是 `{data:...}`），数组元素按 `lx` 分三类：
  - `kb` 上课（本次 N 条）
  - `ks` 考试（3 条）
  - `xk` 选课时间段（6 条）
- `d1/d2` 是**日历可视区间**参数；`xk` 可能返回早于 `d1` 的历史选课（本次 2 条 2026-07 的记录），别假设严格过滤。
- 建议区间：学期开始前 1 个月 ~ 学期结束后 2 个月。

### 取数三种办法（按可靠性排序）

**A. 借用已登录页面执行 fetch（推荐）**

浏览器桥接/DevTools 里，在该域名页面上下文执行：

```js
fetch('/new/desktop/getCalendar', {
  method: 'POST',
  credentials: 'same-origin',
  headers: {'Content-Type': 'application/x-www-form-urlencoded; charset=UTF-8'},
  body: new URLSearchParams({d1: '2026-08-01 00:00:00', d2: '2027-03-01 00:00:00'}).toString()
}).then(r => r.json())
```

把结果原样落盘成 `calendar_raw.json`（数组，或 `{status,url,data}` 包装都行，`jw_normalize.py` 两种都认）。

**B. DevTools 手工**：打开课表页 → Network → 筛 `getCalendar` → 右键 Copy response → 存文件。

**C. cookie + curl**：从浏览器导出 cookie 头，`curl -b cookies.txt -X POST ...`。仅当 A/B 都不方便时用。

> 桥接的坑：tab/session 会被 `navigate` 重建，跳转后 `snapshot` 报 “tab was closed” 属正常；桥接同时连了多个浏览器时 `find_tab` 可能借用错标签，需要让用户把目标页面固定在前台。详见 `05-lessons-pitfalls.md`。

## 3. 字段字典

| 字段 | 含义 | 说明 |
|---|---|---|
| `dm` | 记录 ID | 唯一；`sourceId` 用它派生 |
| `lx` | 类型 | `kb` 上课 / `ks` 考试 / `xk` 选课时间 |
| `kcmc` | 课程名 | 可能带 `(上)`、`（慕课）` 等后缀 |
| `kcbh` | 课程编号 | 如 `TMP0096` |
| `kcptbh` | 平台课程编号 | 如 `50839` |
| `jxhjmc` | 教学环节 | 理论教学 / 实验教学 |
| `kxh` | 课序号 | 同课多班时区分 |
| `qsrq` / `jsrq` | 起 / 止日期 | `YYYY-MM-DD`，同日或跨日 |
| `qssj` / `jssj` | 起 / 止时刻 | `HH:mm:ss`，**注意可能有前导空格** |
| `zc` | 教学周 | 1..23，本次实际 1..19 |
| `xq` | 星期 | 1=周一 … 7=周日 |
| `jcdm` | 节次代码 | 两位一段：`010203`→1、2、3；`111213`→11、12、13 |
| `teaxms` | 授课教师 | 多教师以逗号分隔 |
| `sknrjj` | 授课内容 | 本条最有价值；可能含换行、含“（上课时间10：20-15：40）” |
| `jxcdmc` | 教学场地 | 可能为空（慕课/未排教室） |
| `xqmc` | 校区 | 如“大学城” |
| `jxbmc` | 上课班级 | 如“示例班级A,药24示例班级B(班)” |
| `khfsmc` | 考核方式 | 考试 / 考查 |
| `pkrs` / `jxbrs` | 排课 / 上课人数 | |
| `zwh` | 座位号 | 考试用；上课记录一般无意义 |
| `jxxsmc` | 教学形式 | 常为空或“线下教学” |
| `bz` | 备注 | 大多为空 |
| `bgcolor` | 颜色 | 与业务无关 |

## 4. 语义校验（`jw_normalize.py` 内置，别跳过）

1. **日期 = 星期**：`qsrq` 的星期几必须等于 `xq`。
2. **周次线性**：同一课程同一星期，`qsrq - (zc-1)*7` 必须恒定，据此反推第 1 周周一。
   - 本次：第 1 周周一 `2026-09-07`；周历网格（官方 xls）按周日起排，所以第 1 周网格起点是 `2026-09-06`；首次上课 `2026-09-07`，末次 `2027-01-12`，共 19 周。
   - 两个数字都别混：**锚点是周一 2026-09-07**，网格首列是周日 2026-09-06。
3. **结束晚于开始**：跨日也要成立。
4. **条数对得上官方版**：见下一节。
5. **异常标注条数**（本次基线）：notes 非空 **44 条**（共 46 行）= 无场地 29 + 时间重叠 12 + 平行排课 2 + 内容时段不一致 3。数值高于是文档笔误的常见来源，验收时以脚本实际输出为准。

## 5. 官方导出 `calendar.xls` 怎么用

- 格式：OLE2 的 `.xls`（不是 CSV 伪装的）。用 `xlrd`（`encoding_override='gbk'`）读；Excel 打开是“兼容性模式”。
- 内容：标题 + 23 周 × 7 天的网格（**只有课程简称**）+ 底部“课表摘要”约 若干行规则文本。
- 摘要行格式：

```
示例课程★第1-2,5-8,11-12,14-15周★星期4★020304节★教学楼B105（智慧课室）★示例班级A
```

展开规则（周次支持 `1-2,5,7-8` 这种区间），得到与接口条数一致的排课记录集合（两边条数必须相等）。**这是判断“接口有没有少给”的唯一权威对照**。

- 网格还能反推学期周起点：找带月份标记的列（如第 4 周列头“10月”+周四），减 `(week-1)*7` 得第 1 周起点。

## 6. 换学校/换学期要改什么

只改这一层：

1. `jw_normalize.py` 顶部的 `FIELD_MAP`（把对方字段名映射到统一语义）。
2. 取数 URL、表单字段、学期参数。
3. 官方导出格式（若对方没有，去掉交叉校验并在最终回复里说明“无第二来源可对账”）。
4. 时间/星期口径（有的学校 `xq=0` 表示周日，有的用 `星期几` 文本）。

后面的 `build_artifacts.py` / `feishu_calendar_push.py` / 多维表格命令**不用动**。
